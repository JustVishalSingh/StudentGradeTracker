# CodeAlpha Student Academic Performance Management System

## Problem Statement
Managing student records and grades manually using spreadsheets is inefficient and prone to errors. Educational institutions need a streamlined, digital solution to track student performance, calculate grades, and generate reports.

## Solution
This project is a desktop-based Java application built to manage student academic records, subjects, teachers, and grades. It features role-based access control, analytics dashboards, and report generation capabilities.

## Technologies Used
- **Java 17**: Core language
- **JavaFX**: Desktop UI Framework
- **MySQL**: Relational Database for persistence
- **JDBC**: Database communication
- **Maven**: Build and dependency management
- **JUnit 5**: Unit Testing (planned)

## How to Run
1. Install **Java 17** and **MySQL**.
2. Run the SQL script found in `database/schema.sql` to create the database.
3. Update `src/main/resources/config.properties` with your database credentials.
4. Run using Maven: `mvn clean javafx:run`
5. Default login: Username `admin` / Password `admin123`
